# Product behavior specifications

Write a feature's purpose, behavior, platform coverage, shared contracts, and acceptance scenarios here before its implementation needs clarification. Start from [the feature-spec template](../../tooling/templates/feature-spec.md).

Use concrete scenarios that each applicable native platform can verify. Record intentional platform differences rather than treating one platform's implementation as the specification.

This template currently has no product domain. Its initial design and implementation plan are retained in `docs/superpowers/` as provenance, not as a mandatory workflow for adopting projects.
