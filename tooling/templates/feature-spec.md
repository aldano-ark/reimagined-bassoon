# Feature specification

## Purpose

Describe who needs the feature and the outcome it provides.

## User-visible behavior

Define actions, states, validation, failure handling, and recovery.

## Platform coverage

List affected platforms and intentional differences. State which platforms are excluded from this work.

## Shared contracts

Link relevant schemas, fixtures, or service interfaces. State whether an existing contract changes.

## Acceptance scenarios

Write observable scenarios with initial state, action, and expected result for each applicable platform.

## Verification

List required checks and evidence that would demonstrate the acceptance scenarios.
