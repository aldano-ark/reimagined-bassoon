# Work item

## Objective

State the concrete outcome and link its feature specification or issue.

## Authorized completion boundary

Record the requested end state, such as a verified local change or a reviewed pull request, and any actions outside the task's authorization.

## Scope and files

List owned areas and expected changes. Identify shared files that need coordination.

## Affected platforms

List platforms and the behavior each must deliver.

## Dependencies

List prerequisites, external access, and decisions needed for completion.

## Acceptance criteria

Define observable conditions that make the work complete.

## Commands

List the commands or manual procedures that verify this work.

## Results and evidence

Record actual command statuses, artifact paths, runtime observations, and unverified checks. Keep build, lint, and launch evidence distinct.

## Handoff and blockers

State remaining work, specific blockers, and the next action or owner. An autonomous task follows the same reporting contract as a human-assisted task.
